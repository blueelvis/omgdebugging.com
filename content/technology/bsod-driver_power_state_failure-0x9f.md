Bugcheck Code – Driver_Power_State_Failure (9F)

What the problems were –

- Getting BSOD sometimes while shutting down / booting the laptop.
- System crashing generally when playing games, browsing on Chrome or simply idle.

System – Custom laptop made from CLEVO Kit

Solution –

- NVIDIA Graphics drivers needed to be removed and then install the drivers supplied in the Driver Disc.
